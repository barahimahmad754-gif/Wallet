# دفتر التسميع — نسخة التطبيق مع الإشعارات والأيقونة

هذا المجلد هو واجهة «دفتر التسميع» مستضافة على GitHub Pages.
البيانات تبقى كما هي في مشروعك على Google Apps Script؛ الواجهة فقط انتقلت إلى هنا
لأن رابط Google لا يسمح بأيقونة خاصة ولا بإشعارات.

## الملفات

| الملف | وظيفته |
| --- | --- |
| `index.html` | التطبيق نفسه |
| `config.js` | رابط مشروعك في Apps Script (سطر واحد تعدّله) |
| `sw.js` | يستقبل الإشعارات ويفتح التطبيق عند ضعف الاتصال |
| `manifest.webmanifest` والأيقونات | اسم التطبيق وأيقونته على الشاشة الرئيسية |
| `server/Push.gs` | ملف تضيفه إلى مشروع Apps Script ليرسل الإشعارات |

## التركيب (مرة واحدة)

### ١) في مشروع Apps Script

1. افتح المشروع، اضغط **+** بجانب «الملفات» ← **سكربت**، وسمِّه `Push`.
2. الصق فيه محتوى `server/Push.gs` كاملًا واحفظ.
3. من القائمة أعلى المحرر اختر الدالة `pushSetup` واضغط **تشغيل**، ووافق على الأذونات.
4. **نشر ← إدارة عمليات النشر ← تعديل (القلم) ← الإصدار: إصدار جديد ← نشر**.
   تأكد أن «من لديه حق الوصول» = **أي شخص**.
5. انسخ رابط تطبيق الويب (ينتهي بـ `/exec`).

> إن كان في مشروعك دالة باسم `doPost` من قبل فأخبرني قبل إضافة الملف، لأن `Push.gs` يعرّف `doPost` خاصًّا به.

### ٢) في هذا المجلد

افتح `config.js` وضع الرابط بين علامتي التنصيص:

```js
window.TASMEE_API = "https://script.google.com/macros/s/XXXXXXXX/exec";
```

### ٣) تفعيل GitHub Pages

في المستودع: **Settings ← Pages ← Branch: `main` ← المجلد `/ (root)` ← Save**.
بعد دقيقة يصير رابط التطبيق:

```
https://barahimahmad754-gif.github.io/Wallet/tasmee/
```

## ما يفعله الطالب

1. يفتح الرابط الجديد ويختار اسمه.
2. **آيفون:** يفتحه في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية»، ثم يفتح الدفتر من الأيقونة
   (الإشعارات على الآيفون تعمل من الأيقونة فقط، ومن iOS 16.4 فما فوق).
   **أندرويد:** يكفي Chrome، ويُفضَّل «تثبيت التطبيق» من قائمة المتصفح.
3. يضغط **تفعيل** في بطاقة «فعّل الإشعارات» ويوافق.

رابط كل طالب الخاص (من «المزيد ← الأسماء والروابط») صار يشير إلى الرابط الجديد تلقائيًا.

## ما يصل للطالب

| الإشعار | متى |
| --- | --- |
| تذكير التسميع | يوميًا في الساعة التي تحددها (الأحد–الخميس) لمن لم يُسجَّل له تسميع، عدا المستأذن |
| نتيجة التسميع | فور أن يسجّل له زميله أو المعلم القريبة أو البعيدة |
| نتيجة الدرس أو الاختبار | فور أن يسجّل المعلم «اجتاز» أو «يُعاد» |
| رسالة من المعلم | من «المزيد ← الإشعارات»، لكل الطلاب أو لطالب واحد |
| تنبيه غياب | من شاشة الحضور: زر «نبّه الغائبين بإشعار» |

التحكم كله من **المزيد ← الإشعارات**: إرسال رسالة، تشغيل وإيقاف التذكير ونتائج التسميع،
وقت التذكير، ومن فعّل الإشعارات ومن لم يفعّل.

## ملاحظات

- الرابط القديم على Google يبقى يعمل كما هو، لكن بلا إشعارات.
- الإشعار يصل للجهاز الذي فُعّل منه فقط؛ إن غيّر الطالب جواله يفعّل من جديد.
- وقت التذكير بتوقيت مشروع Apps Script (إعدادات المشروع ← المنطقة الزمنية).
